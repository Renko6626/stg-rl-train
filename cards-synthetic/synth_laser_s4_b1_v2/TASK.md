# synth_laser_s4_b1_v2

## 变异几何与时间

- 开场等待 120 帧；每轮创建 1 条从随机原点瞄向自机的激光，使用 `lz_aim`，再叠加随机偏角 `[-1024,1024] BAM`。
- 原点 `x∈[-100,100]`、`y∈[70,170]`，颜色 15、长度 400px；warn 60、active 45、fade 12。
- rank 0/1/2/3 的完整宽度分别为 6/8/10/12px；每 240 帧一轮，共 10 轮。每轮三次 RNG，seed 1/7 的原点和偏角应有几何差异。
- 首条出生 harness 帧 123，末条出生 1803，约 2400 帧内自然回收。
- 最后一条自然回收帧按 harness 帧序 `1803 + 60 + 45 + 12 = 1920` 计算，未超过时限。

## 关键帧预期

- 124：1 条 state 0，`start=0,end=400`，原点和宽度在上述范围，角度为原点自机方向加偏角。
- 184：1 条 state 1；214：1 条 state 1，几何长度不变；228：state 2；240 及 254：0 条。
- 364：第二条 state 0，重新采样原点和偏角。
