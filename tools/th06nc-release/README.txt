TH06NC AI 代打插件
2026-10-28版本

1. 安装
关闭游戏，备份游戏目录中已有的同名文件，再把本包文件复制到 th06nc.exe 旁。
请一起复制 th06nc_autoplay.ini，它会启用本包模型。像平常一样启动游戏即可。
仅适用于已适配的 64 位 TH06NC，不能用于原版 th06 或其他作品。
需要系统已安装 Microsoft Visual C++ 2015–2022 x64 运行库；本包沿用原有加载方式。

2. 操作

默认从手动模式开始。按 C 依次切换：手动 → AUTO → BYPASS → 手动。
AUTO 模式：让AI自由躲子弹躲子弹。
BYPASS 模式：让AI躲子弹时尽可能追踪敌人，压力大时自由躲子弹。
两个代打模式都自动射击，并在危险时使用炸弹，同时支持使用按住鼠标左键，引导自机去指定位置。
手动按键也可以强制接管AI操作。

3. 模型
这是一个在合成的弹幕数据集上，使用大规模PPO强化学习训练的模型。
该项目的目的是创造一个“拟人化”的AI，因而在训练时，AI的【操作频率和精度】都会受到巨大限制：
AI的所有按键操作都会“持续数帧，而且时长有误差”，它观测到的子弹数据同样不完全精确。
且它在强化学习时也加入了拟人化的奖励函数。因此它不会出现纯算法方案的“高速抽搐”或者“令人惊叹的神穿”。

模型的主要基于注意力机制，将周围子弹/激光/敌人进行编码并进行自注意力，同时引入CNN感知全局密度。
它的训练大概需要A100卡工作3小时（或者4090卡6小时），具体数据会在我们之后的技术报告放出。

4. 遇到问题
HUD 显示 ONNX 表示模型已加载；若显示 BUILTIN (onnx failed)，查看 th06nc_autoplay.log。
先确认 model.onnx、onnxruntime.dll 和配置都在游戏目录，且系统运行库齐全。
卸载时关闭游戏，删除本包安装的文件，并恢复安装前备份的同名文件。
