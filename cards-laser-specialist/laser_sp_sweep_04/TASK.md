# laser_sp_sweep_04 — 侧边非对称双扫

状态：READY/FROZEN（作者 round 1 修订，仅作者阶段）。布局族 `sweep`，split `held-out`。

## 设计

每轮从左右侧缘各出生一条长线，第二条比第一条晚 44 帧。左侧线与右侧线使用不同的 x/y 抽样区间、独立的 BAM 起角扰动和相反旋向；两条线不镜像复制。每轮间隔随 rank 为 147/148/149/151 帧，首轮延迟开场后开始，之后交错预警和生效。每条线长度固定 390 px，出生时静止；预警结束后才设置非零 `lz_omega`，所以预警期间不转，生效和收缩期间按真实连续 omega 转动。

各档宽度/预警帧数依契约为 6/90、8/75、10/60、12/45。生效 180 帧、收缩 12 帧。角速度绝对值按 rank 为 36/48/60/72 BAM/帧，左转负、右转正。左侧起角基准按 rank 为 34°/42°/50°/58°，右侧恒为 165°；两边分别叠加独立 `[-2730,2730]` BAM 扰动（约 ±15°）；位置和相位也独立随机。左原点 x 为整数像素 `[-174,-150]`、y 为 `[100,350]`；右原点 x `[150,174]`、y `[150,300]`。`rand(n)` 为 `[0,n)`，因此代码使用减基数表达闭区间端点。位置按整数像素后转 fx；角扰动是 BAM 原值，按 `int as angle` 位穿透后加到角度上。

### 调度和边界预期

主任务在首个脚本帧创建无敌、无身体碰撞 boss `(0,64)`，开始 1800 帧 `phase_begin(..., 1800, 0)`。模式任务首轮等 88 帧，经子协程次帧启动后首线实测为帧 93；左线同帧生成后，右线延迟 44 帧；之后周期依 rank 为 147/148/149/151 帧。十轮左侧首帧为 93，最末轮左侧实测为 1416/1425/1434/1452，右侧为 1460/1469/1478/1496。最后一条自然回收实测为帧 1742/1736/1730/1733（出生 + warn + 180 + fade 12）；最后 fade 帧分别为 1741/1735/1729/1732。

每条线在出生帧为预警、长度 390、start 0；到出生后 `warn` 帧设置 omega 并进入生效期，生效 180 帧、fade 12 帧。`--at` 实测确认首线在帧 93 为 state 0；帧 183/168/153/138 首线分别在对应 rank 的 warn 结束转 state 1 并首次显示非零 omega；末 fade 帧为 state 2 timer 12，下一帧自然回收。双线数量实测峰值 4：同侧周期 147..151 帧，小于最短完整生命周期 237 帧，但同侧至多两条；左/右间隔 44 帧。八组全跑的最大激光计数为4，故预警+生效≤16、含fade≤20。预警/生效内部最长空档推导并由波次关键帧确认是0帧（开场与收尾不计）。

### 避让空间与最不利组合

屏幕 playfield 采用 x `[-192,192]`、y `[0,448]`。每条线长 390 px；在四边交点中，水平跨场方向的最远需要约 366 px，垂直余量由旋转和不同 y 抽样提供。左侧线角度初始约为 rank 基准 ±15°，生效中连续减去 `35.6..71.2°`；右侧从 `150..180°` 连续加上同样的 rank 角度量。四角的可达示例均取自实际允许的原点带：左源 `(−150,100)` 到右上角 `(192,0)`，距离约 356.3 px、方向 −16.3°；左源 `(−150,350)` 到右下角 `(192,448)`，距离约 355.8 px、方向 16.0°；右源 `(150,150)` 到左上角 `(−192,0)`，距离约 373.5 px、归一化方向 203.7°；右源 `(150,300)` 到左下角 `(−192,448)`，距离约 372.6 px、方向 156.6°。这些点说明允许原点和扫角内存在能覆盖角部的几何实例，不证明每个角在实际随机序列中都会被扫到，也不证明不存在可静止存活的位置。左、右原点 y 带重叠但分布不同，起角、时相、旋向也不镜像。下一线预警时旧线仍生效，形成跨场交接。宽度逐档随契约加宽，预警随档缩短，角速度逐档增大。

最不利 rank 3：width 12 px，warn 45 帧，active 180 帧，长度 390 px，omega 72 BAM/帧。连续角位移每帧约 0.3955°，线段最远端切向速度约 `390 * 72 * 2π / 65536 = 2.70 px/frame`，低于 3.5 px/frame。最不利 rank 0：长度 390、omega 36 BAM/帧，远端切向速度约 1.35 px/frame；起角扰动按 2730 BAM 计。原点距左右边界至少 18 px；上面的四条射线是四个具体角点实例，不代表对边界的连续覆盖或迫使玩家离开某个静止点。预警线不转，故最短预警期内有 45 帧反应时间。该运动界限只覆盖固定长度、离散整数像素端点和给定 rank/seed 的几何范围；真实玩家控制、动作冷却及全部随机实例尚待独立避让工具检查。

### 骨架

仅一只固定 boss，无普通子弹：`spawn_enemy(0fx, 64fx, 1000, 0, 0, 0, boss_main)`；主任务设置 65535 帧无敌、`ENEMY_NO_BODY`，调用 `phase_begin(0, sweep_pattern, 1800, 0)` 并等待段结束。是否满足固定目标/无碰撞依实际 harness 诊断和关键帧确认。卡片不创建底子字段、来源引用或 provenance。
