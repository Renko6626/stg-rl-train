# 横向相向短棒流（laser_sp_bars_02）

## 设计与时序

每轮两根有限水平棒从左右场外相向进入：左侧以 `0deg` 向右，右侧以 `180deg` 向左。通常两根棒的y行错开约224px；第0/4/8/12/16轮固定走y=0与y=448边界行，覆盖四角而不封闭整条横向通道。每轮间隔83帧，共17轮。其余行基值按 `((wave*56)%449)` 与 `((wave*56+224)%449)` 轮换并加入有限随机抖动，覆盖边缘与中间行。

运行实测：phase 开始后 pattern 等待 90 帧，pattern 的新协程首跑延迟与 laser 创建任务首跑合计使首束出生于第 95 帧；第 94 帧没有激光。第 n 轮出生帧为 `95 + 83*n`，n 为 0..16，末轮第 1423 帧。运动机制为**原点平移**：预警期原点静止；warn 结束后每 active 帧调用 `lz_origin`，左来向的正速率沿射线向右平移、右来向沿射线向左平移；整个生命周期 near=0、far=随机初始棒长不变。rank0/1/2/3 的第一根首个 active 快照依次在 185/170/155/140 帧。速度标量为正，1.0/1.1/1.5/2.0 px/frame。所有 rank 的 active 为 210、fade 为 12。最后回收上界按最长 warn 推导为 `1423 + 90 + 210 + 12 = 1735` 帧；引擎抽帧核对后应不晚于此值，低于 1750 的统一上限。

rank0/1/2/3的width为6/8/10/12px，warn为90/75/60/45帧，speed为1.0/1.1/1.5/2.0px/frame。随机棒长为 `[80,120]` 整数像素（含端点），左右出生x抖动为 `[-24,24]` 整数像素（含端点）；非边界y行抖动为 `[-24,24]`（含端点）；`rand(49)` 生成 `[0,49)` 后减24。`int as fx` 是数值换算像素。每第0/4/8/12/16轮边界行固定为y=0/448，其他行由轮换与抖动生成。左右线长、推进速度、warn和宽度按rank联合变化；不对随机变量各自独立扩范围。最短长度80与最慢速度1.0、最长active210的水平推进总量至少290px，可从最内侧出生点 `x=-216` 推过中轴至 `x=74`；右侧对称。最大组合推进 `2.0*210+120=540px`，小于引擎激光长度640px上限。

## 练习空间与覆盖边界

出生原点在x∈[-264,-216]与[216,264]，有限段由场外驶入；实际判定区域x∈[-192,192]，因此两侧边缘均被来向棒穿过。每4轮的边界行固定为y=0和448，左右短棒沿边界行驶入并扫过四角；其他y行覆盖中间区域，抖动可能略出屏但不要求自机离开clamp范围。每轮最多两条，条带为80..120px短段，绝不构成横贯全屏的墙。玩家可以沿条带端点上下绕行，再为下一轮换行；行序在整段内持续变化。几何边界推导不代替真实自机避让和站桩检查。

预警+生效同时活跃的最坏估算不超过 `2 * ceil((90+210)/83) = 8`；计入 12 帧 fade 仍不超过 8，低于 16/20 预算。相邻波出生间隔 83 帧，前波的预警/生效覆盖下一波出生，因此内部无预警/生效空档，`max_idle_gap=0`（开场和收尾不计内部空档）。每档两种子基础运行和关键帧应确认该预算。卡仅含激光，无普通弹；固定 boss 位于 `(0,64)`，1800 帧非符段，HP 阈值 0、无敌且 `ENEMY_NO_BODY`，主协程在 `wait_spell()` 后存活。

## 随机与证据范围

跨种子有左右x、非边界y行和棒长随机差异；边界行确保四角在整段中受练。种子1/7仅用于本次作者自检，不能代表所有随机实例。长度与推进速度的组合均保持正速；ECL不依赖负速、钳制或坏句柄降级。关键帧核对原点逐帧位移，以及near/far全程保持 `[0,len]`。完整玩家动作/判定下的可解性、四角站桩轨迹与全随机域覆盖仍待协调者的独立工具验证。
