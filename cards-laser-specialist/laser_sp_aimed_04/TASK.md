# laser_sp_aimed_04 — 上侧三原点错峰出生瞄准

状态：作者实现中。布局为 held-out，契约 v1。段由一只固定 `(0,64)`、无敌、无体碰 boss 持有，纯激光，不设 `lz_aim`、`lz_omega` 或 `lz_rotate`。

每组在同一出生帧从上侧三个原点之一发出三条线：一条 `offset=0deg` 中心直狙，两条相对中心方向 `±d` 的侧线；三原点是 `(-184,16)`、`(0,16)`、`(184,16)`。原点按 `rand(3)` 选取的起点后轮转，因此各组交替覆盖三处。每条线都在出生时用该原点至当时 `$player_x/$player_y` 的 `atan2(dy,dx)` 算方向，侧线只在出生时加减固定随机偏角，此后方向冻结。每组共 3 条，中心线提供直接威胁，侧线拓宽移动决策。

## 帧时序与预算

`phase_begin(0, aimed_groups, 1800, 0)` 管理 1800 帧；实际 `PHASE_ENDED@1803`，因为 boss/phase 任务在开局调度后启动。pattern 首次等待 90 帧，harness 在帧 93 仍见 0 条、帧 94 首次见 3 条（`timer=1`），所以实测 `first_spawn_frame=94`。后续组间隔由 `72 + rand(19)` 得到 `[72,90]` 整数帧（端点含），最大新预警空档为 90 帧。每组 3 条同时出生；最坏最长寿命为 rank3 的 `45+210+12=267` 帧。最短间隔 72 帧下最多 4 组同时存活，即预警+生效最多 12 条、含 fade 的池占用最多 12 条；完整矩阵实测激光峰值 12。独立逐帧 handle 追踪确认跨矩阵最后出生为帧 1478；各 rank 最后回收前/后快照为 r0 `1729/1730`、r1 `1734/1735`、r2 `1739/1740`、r3 `1744/1745`（seed7 在前一帧仍有 3 条收缩线，后一帧清空）。两种子所有 rank 在帧 1800 都为零激光。`--at` 出生边界样本见 `recheck-r*-s*-f1477.log`、`recheck-r*-s*-f1478.log`，回收和时限样本见 `lifecycle-r*-s*-f*.log` 与 `terminal-r*-s*-f1800.log`。

为保证自然回收不晚于 1750，出生前按 rank 检查 `spell_timer() > warn+active+62`；该 62 包含段末差 50 帧与 fade 12 帧。阈值分别为 rank0 302、rank1 307、rank2 312、rank3 317。条件不足时不再出生，已有线自然经过预警、生效、收缩后回收。

## 随机范围与联合约束

`rand(3)` 返回 `[0,3)`，均匀整数起始原点；随后固定轮转，避免某个原点长期不出线。`rand(3)` 另选 `d ∈ {8°,16°,24°}`（三点离散均匀，端点包括 8°/24°）；侧线偏角绝对值都在任务允许的 8°..60°。`72+rand(19)` 返回 `[72,91)`，即 72..90 帧含端点。同一组宽度、预警、寿命和间隔一起受 rank 约束，且每组都有直狙与左右对称侧线，不会出现随机配置删除中心威胁的组合。间隔与偏角各自由世界 RNG 抽取；seed1/7 实测首组位置和侧角有差异，但它们不代表全分布。

方向角由 `atan2($player_y-16fx, $player_x-x)` 从激光原点计算，不是从 boss 位置计算。这里没有 `int as fx` 或 `int as angle` 转换：角度偏移使用 `8deg/16deg/24deg` 字面量。宽度是完整判定宽，使用 `6.0fx/8.0fx/10.0fx/12.0fx`；没有旧原作宽度换算。

## 空间与站位评估

每个新组中心线经过出生瞬间自机位置；预警期为 Easy 至 Lunatic 的 90/75/60/45 帧，要求自机离开 6/8/10/12px 宽的线带。侧线在距原点 `r` 的玩家位置处与中心点的横向偏差约为 `r·sin(d)`，联合压力端点是 Lunatic 的 12px 宽、45帧预警、24°侧线；最窄侧线角是 8°，在与中心线近处保留较窄的躲避分流。各rank完整harness无输入采样都观察到12条峰值；这只核查时序与几何，不代表移动自机的真实生存余量。原点会在左右上方和正上方轮换，所以空间约束随当前出生位置改变。

角落/顶部站桩：中心线会在每组出生时直接瞄准静止自机，因而任何固定 clamp 点都不能靠“偏角让开所有新线”永久安全；至少需要离开中心线带。侧线对顶部近原点有重叠可能，远离原点时应按 `r·sin(d)` 计算，不能把 8°当成全场安全封锁。底部角落到最近上侧原点距离很大，侧线本身可能留有较宽空隙，但随后中心线仍直接瞄准该点。此处是几何推导，不是玩家存活或站桩实测；真实动作/判定余量由协调者的独立检查器验证。
