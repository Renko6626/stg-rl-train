# 首轮调研结论

日期：2026-11-02。依据为这轮读取的 Priw8 网站数据、renkolab 指定版本的原生逆向资料和我方 `ENGINE_VER27` 源码。逐项记录是静态研究结论，不能当作本轮原作逐帧对拍通过。浮点/定点及弧度/BAM精度差异按用户要求不影响分类。

**2026-11-03复核**：用户要求按LLM重写完整攻击判断必要性。第五类的必改范围已显著收窄，见[实际缺口复核](gap-recheck-2026-11-03.md)；本页保留初版调查经过，不直接作为实施清单。

## 五类结果如何使用

| 类别 | 本轮确认的代表行为 | 限制与后续 |
|---|---|---|
| 1：直接精准 | 同敌共享 I0..I3/F0..F7 的读写、敌/自机坐标与当前生命读口、有效域内的标量运算；部分发射器字段 setter | 只证明该行操作，不自动证明整段攻击、碰撞或生命周期等价。共享变量已在源码，不代表旧 wheel 或导入器已接。 |
| 2：组合精准 | 固定调用图的调用栈降低、整数脚本时钟子集、普通发射几何、速度端点转步长、TH16 两套偏移缓存合成、TH06 ex12/14沿本敌激光发弹 | 每行写明容量、调用深度、状态归属与同帧预算条件。已给可操作配方；尚无配方或预算依据的项不能因为“理论上能写”就列2。 |
| 3：组合近似 | 新敌首跑晚一帧、圆形清弹在位移后生效、部分弹任务替代 EX、旧卡的夹终点/动态角量化/时停压平、TH06 delete 映成 die 的结算副作用 | 保留具体差异。部分是已有转换写法的近似，不等于引擎所有可能组合都无法改善。 |
| 4：取舍可不做 | TH06 单段训练已批准的若干表现/对话/跨段流程省略；现代声音、血条、纯显示等为新建议 | 结构化表的 `decision=existing/proposed` 分开。新增省略仍待用户确认；ANM驱动出生态不能按纯表现省略。 |
| 5：缺少且关键 | 所选攻击内部确实依赖的敌共享发射器/EX程序、出生态、曲线与动态危险区、async取消域，以及 TH06 ex15 跨弹邻域与原池机制候选 | 是需要进一步定方案的缺口，不是实施授权；应按具体攻击选择最小功能，不按原作指令总量建设完整 VM。 |

类别并非每个 opcode 一个无条件标签。同一指令的静态参数子集、动态改写和不同作品可以有不同结论。[逐编号索引](instruction-index.csv)保留关联的所有行为行；[可筛选行为矩阵](behavior-matrix.csv)给出条件、配方、差异、原作与我方证据、导入状态、取舍状态。不要只看类别一列。

## 对 TH06NC 旧卡池的直接影响

当前流水线历史记录为166个 collected、10个 excluded；本轮另核 `unit.json.skip`，没有重新生产、验收或改动这些卡。状态日志与单元摘录可能来自不同阶段，报告保留各自口径。

- ex12/14 已有当前几何读口与组合方法，旧“不能沿激光发弹”的限制不再适用。
- ex7 是局部几何生成，并非全场激光扫描；但是48次创建连同几何计算能否在现有单帧预算内完成，或者预建任务如何可靠同帧触发，尚未给出完整配方。因此本轮留待核实，**不直接宣布可收卡，也不直接认定需要新引擎机制**。
- ex8/9/11 的预挂弹任务替代受任务数量、原弹池顺序和执行相位限制，当前仅列近似；ex15 的大弹与小弹邻域关联值得另提最小方案。
- NC新增回调17–19与201的完整动态表现仍有证据缺口，不能因为不懂就列“关键应做”，也不能静默删掉。
- 旧卡固定无敌是训练取舍，不能拿它证明当前引擎没有生命读口。读口能力、公式表达能力与旧卡实际采用已在表中分开。

详见 [TH06/NC报告](th06.md)与 [结构化记录](th06.json)。

## 建议的下一步边界

1. 先用代表性完整攻击落实表中2类规则，并验证其明确条件；不要用“原型当前不接”代替能力判断。
2. 对确实阻塞目标攻击的共享发射器、EX状态/出生态、曲线几何等逐项提出方案，列能新增哪些攻击及简单替代办法，再由用户选择。
3. TH06原池、ex15、现代async取消/时钟和碰撞框按样本实际依赖安排；池上限数字或原作一般性需求本身不构成立即扩功能的理由。
4. 完整动态rank、炸弹伤害、一般运行中HP和多段Boss/死亡中断已记录能力差异，但**固定rank、单段、敌无敌的躲弹卡不以它们为扩样前置**。本轮将其重要性留待目标变化后确认，不混进当前必做清单。

新声音/表现省略建议也未自动成为既定取舍。现有转换器、卡池和训练 wheel 均保持原状。

## 覆盖与未完成项

TH06/NC为151个候选键，TH16为300个候选编号；均有记录入口。另有TH06的变量/20个回调，以及TH16的98个变量、13种发射模式和29个EX项。一个编号可能关联多个条件行为，不能把行为记录数当有效指令数。

没有充分行为证据、没有可落地组合配方，或重要性仍待取舍的记录保留 `category=null`，并写明原因。主要包括NC新增回调、ex7完整预算、现代部分硬编码函数、模式11/12的调速公式、Beam路径、部分特殊变量和一般32位按位组合。主表覆盖不等于这些项已经定类。
