## s4_w04的确证与对照

原文`st04.ecl.txt:793–809`的控制流：

```text
B = 1
goto condition
body: etOn(); wait(3)
condition: if (B--) goto body
wait(gap)
```

第一次条件读1并减为0，执行一次body；第二次条件读0退出。原目标把它写成`for vol in 0..2`，每轮两次发射。临时副本只改成`0..1`，保留`if vol == 0 { wait(3); }`，因此原有轮间总等待不变。

## 对容量结论的限制

- 原日志的pool_full是**全程累计分配失败次数**，不是池容量或同时需求峰值，不能用256+1297推算激光峰值。
- s3/s4的段不是在加速效果结束时释放，而是随弹回收，故效果只持续60/120帧也可能长时间占池。
- 两张五面卡用当前配方得到的单条回收时间约为`(640+102.4)/4≈186`帧；这是目标行为，不能当作已核的TH16原作回收时长。当前无敌外壳还允许可击破小怪持续发射至自然出界。
- 五张中已有一张的池满可由明确转写错误解释。其余应在核准确切发射语义及回收差异后，再判断容量或训练取舍；本轮不新增取舍。
