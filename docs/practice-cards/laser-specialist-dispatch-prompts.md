# 激光专项卡：派发 prompt 模板

2026-10-01。用途：为下一轮数据合成准备可复用的作者、独立审查和返工指令。依据 [专项设计方向](2026-09-30-laser-specialist-design.md)、[试产经验](2026-09-27-pilot-retrospective.md) 和第二批审查发现整理；并非找回了历史派发 prompt 原文。本次只准备模板，未启动合成或训练。

## 下一轮合成什么

从零编排以激光为绝对主体的专项卡，首批可完全没有普通子弹。通过波次交接持续提供观察、选位、移动或等待的机会；已有 30 张混合 overlay 卡继续承担混合练习。

| 候选家族 | 核心机制 | 逐卡规格必须交代 | 重点排查 |
|---|---|---|---|
| 错峰穿行 | 横、竖、斜长线错峰预警、生效、消退 | 各组方向、位置、生命周期、交接窗口 | 交接瞬间封死、永久角落安全 |
| 平移走廊 | 长线原点连续平移，通道移动或变宽 | 通道净宽、原点速度、边界折返和交接 | 通道快于自机、夹到边界、瞬移 |
| 旋转扫场 | 不同原点的长线连续旋转、分批交接 | 原点、起角、角速、开始旋转的状态 | 远端线速度过大、预警期意外旋转 |
| 逐组封位 | 新组按当时自机位置瞄准，旧组继续存在 | 瞄准时刻、偏角、组间隔、旧线是否冻结 | 把新生瞄准误写成持续追踪、预警后突改角 |
| 短棒流场 | 有限长度激光沿射线穿过活动区域 | 近远端、棒长、推进速度、出生和退出区域 | 变成长墙、预警期间已跑离练习区域 |

这些仍是候选家族，尚无已批准的逐卡清单。建议先每家族一个容易的独立布局走通生产与验收，再扩不同布局及较难参数；该建议不确定批次卡数。数量、参数、难度映射、敌人安排及训练/留出划分由协调者在正式派发前冻结。

## 当前接口阻塞与准备边界

核验于 2026-10-01：

- `src/stgtrain/cards.py::discover` 拒绝没有 `base_card` 的 synthetic 卡。
- `src/stgtrain/practice_validate.py` 要求原作底子、逐字还原、单条 overlay 入口、颜色 15、最多四条新增激光及旧参数范围。
- 因此原验收器不能直接作为从零专项卡的通过门。不得伪造 `base_card`、挪用原作血缘或为得到 PASS 擅改验收器。

应先独立解决专项卡元数据/加载器兼容、专项机器门和真实运动下的可执行性检查，再冻结正式任务规格。若提前做 ECL 原型，只能放协调者指定的暂存目录，标记 `PROTOTYPE`，不得纳入训练卡池或称验收完成。本文没有定义已实现的新元数据或 machine-spec schema。

## 公共约束：作者、审查、返工均须附带

```text
目标是提高单位训练预算中的激光避让练习机会。激光数量、死亡率、
重开次数或光效不能替代实际决策机会；不得把推测写成已验证收益。

1. 你不独占仓库。只写任务单授权文件，不覆盖/回退其他人的改动。
   留在 main，不建分支/worktree，不提交、推送、部署或启动训练/Magnus Job；
   不读密钥，不再委派。引擎仓只读；需要新接口报告给协调者。
2. 本任务是从零专项卡。不得机械套用旧 overlay 的四条并发、45帧预警、
   120帧生效等限定；具体值服从本次冻结规格，也不得自行无限放宽。
   首批预警态+生效态激光总数 <=16 是隔离观测截断的设计预算，
   不是引擎容量；池占用还须计入收缩态。普通子弹须符合任务单。
3. 保持真实碰撞和运动机制。禁止改观测/reward，禁止给策略安全路径、
   人工危险度或预知尚未出生的随机未来。离线设计/检查证据不进入策略输入。
4. 波次中旧组生效时，新组可预警；交接要有可执行的空间连通性。
   允许正确避让后停住，等待型局面应能看到消退后行动，不能要求利用
   当前观测没有的剩余寿命倒计时。预警倒计时当前最多表达120帧。
5. 不读取/复刻未分配的留出布局与原作摘录。原创卡显式标记 synthetic；
   无普通底子就不得伪造 base_card、source_ref 或底子 SHA。
   元数据服从已冻结且受工具支持的 schema；接口不支持时返回阻塞。
6. 所有结论绑定当前文件 SHA256。任何代码、TASK、meta、spec 修改
   都使旧机器/审查 PASS 失效。READY/FROZEN 后不得偷偷继续改文件；
   收到返工任务再解冻并生成新快照。
7. 不自动开浏览器点击/填表/交互测试。必要视觉核验最多截图，
   优先源码、真实引擎运行和几何/时序证据；大型产物留在指定临时目录。
```

## 作者 prompt

将公共约束与冻结任务单附在以下正文后。

```text
你是弹幕合成作者。只完成任务单指定的独立卡片，不扩卡、不改共享工具。

先读任务单和对应专项契约，再读以下引擎材料：
/data/sunyunbo/www/stg-engine/.claude/skills/writing-danmaku-ecl/SKILL.md
/data/sunyunbo/www/stg-engine/docs/ecl-lang/9-lasers.md
按需读同目录 2-tasks.md、5-types.md、6-spell-and-stage.md、7-reference.md。
文档例子不覆盖任务约束；遇到语义冲突查实际实现/最小探针，报告证据。

开工前检查任务单齐全、指定工具支持此卡类型、授权路径可写。
若缺关键规格，返回 SPEC_REQUIRED；若接口不支持，返回 INTEGRATION_BLOCKED。
不得靠虚构底子、改共享验收器或提高权限绕过。原型阶段按授权的检查范围工作。

先写简短 TASK 设计，再分段实现与运行核对。设计需说明：
- 每轮时间表：出生/预警/生效/收缩/回收帧、运动开始帧、下一组预警帧；
  根据真实调度验证首次出生和边界帧，不能只把 wait 相加当实测。
- 实际受限空间与练习动作：哪里需要移动，哪里需要等，如何交接到下一组。
- 每个随机量的单位、分布和确切端点；通道宽、速度、预警时长采用联合约束，
  写出最不利组合的避让余量，不能只报告平均值或各参数单独合法。
- 激光数随时间的预算、最长无威胁空档，以及避免固定角落永久绕过的方法。
- 按任务单核对敌人/目标，不能靠无关敌人碰撞制造激光练习的死亡。

重点语义自检：
- width 是完整判定宽，不套原作减半转换；int as fx 是数值转换，
  int as angle 才是 BAM 位穿透（90 as angle 不等于90deg）。
- lz_speed 配置会重置 end=start，随后 end 推进、start 跟进；
  它是沿射线的段推进，原点平移是另一机制。检查预警结束时短棒实际位置。
- lz_omega 在预警/生效/收缩都转；若只生效时转，明确设置时刻。
  lz_rotate 是一次跳转；每N帧跳转不等于逐帧连续旋转。
- lz_aim 从激光原点瞄；aim_player 从owner瞄。逐组出生瞄准与
  已出生激光持续追踪分别描述，不能把前者的设计改成后者。
- lz_origin 解除挂靠。可能失效的句柄先 lz_alive 再写；所有循环需让出执行。
- 新任务首跑有调度偏移；敌主任务 return 会让敌退场。段结束不能意外截断练习。

编译后按任务单矩阵跑完整 time_limit+60 帧，采集首次出生、状态边界前后、
交接/最大重叠、运动中段、随机边界实例、末轮/回收及time_limit关键帧。
正数量快照须有原点、角度、width、start/end、state及必要运动证据。
期望值来自独立推导，不能只复制实际输出再宣称匹配。

退出码0只是必要条件。task_faults/contract_viol/pool_full/hits_ovf/
events_ovf/reqs_dropped 必须全部存在、无重复且为0；缺失/无法解析即不通过。
比较seed1/7的实际几何/时序，颜色变化不算随机化证据。
报告参数边界检查；两个种子不能代表全部随机范围。

按任务单的真实引擎检查器验证避让轨迹和站桩基线。轨迹记录rank、seed、
动作、时长、碰撞、实际运动/判定设置和重放命令。只做离线几何推导、
每帧存在空地或单例成功不能称整个范围可躲；未验证部分明示。

自检结束后冻结所有卡片文件并报 READY/FROZEN（仅表示作者交接就绪）。
若原型缺正式工具，可报 PROTOTYPE_READY 并列缺口，不得声称正式验收通过。
最终只输出：任务/规格版本、状态、变更文件与SHA256、已运行命令和证据路径、
时序/并发/随机范围摘要、未覆盖范围及阻塞。不要贴长日志。
```

可核验的基础命令形式如下；协调者必须填入绝对路径、rank/seed/帧数，不能把它们当专项机器门已实现的证明：

```bash
/data/sunyunbo/www/stg-engine/target/release/stg-harness check <卡片绝对目录>
/data/sunyunbo/www/stg-engine/target/release/stg-harness run <卡片绝对目录> --rank <R> --seed <S> --frames <time_limit+60>
/data/sunyunbo/www/stg-engine/target/release/stg-harness run <卡片绝对目录> --rank <R> --seed <S> --frames <F> --at <F>
```

`harness --at` 的 omega 是配置 BAM/帧；RL token 中是实际角度增量的弧度/帧，包含 rotate。不能只用前者为零否定实际运动。基础 harness 运行也不等于已验证真实玩家动作下的存活。

## 非作者独立审查 prompt

附公共约束、冻结任务单、当前文件哈希清单与机器/可执行性报告路径。审查权限以只读为主，只允许写指定报告；不得直接修卡。

```text
你是独立审查者，不能审自己编写的卡。先核对规格版本、实际文件SHA256
和各报告快照；任何不一致返回 revise，要求重新跑对应门。

读取完整 ECL、TASK、meta/spec、真实机器和可执行性证据；
按作者模板中的引擎文档核实语义。不能把作者注释、报告的ok字段或
机器采样未发现异常当作结论；规格与实现应独立比较。

逐项检查：
1. 授权范围、原创来源、schema、rank映射、敌人/目标和段结束符合任务单。
2. 重算循环轮数/周期/末轮回收；核对状态边界、运动开始、波次重叠和并发峰值。
3. 重算BAM/像素单位、随机区间端点与联合约束；检查机器种子/关键帧
   没覆盖的参数组合。疑似语义问题先查文档/最小探针，再给修改建议。
4. 持续压力来自真实空间约束；允许等待，不要求预知未来/隐含消退倒计时。
   检查通道连通且有运动余量、边界夹死、固定角落/站桩永久绕过。
5. 可执行轨迹确实来自声明的真实引擎运动、判定与动作设置；证据只覆盖
   某些实例时明确限度，不宣称全部随机实例可解或证明训练收益。
6. 诊断字段完整且零；完整时长、关键帧、收尾和随机差异证据均齐全。
   工具不支持/未验证项不能给PASS。

给出 pass/revise/block。每项发现包含：严重度、类别、文件行号、
实际证据、违反的规格、建议和需重验的范围。基础设施阻塞与脚本错误分开。
报告绑定全部卡文件SHA、机器/可执行性报告SHA及审查规格版本。
pass只表示通过本次声明的审查范围，不能代替协调者的最终纳入决定。
```

## 返工 prompt

每轮重附公共约束和同一冻结任务单，避免续接时丢掉来源、权限或观测预算。

```text
你继续负责 <card_id>，本轮为 <round>/3。允许写入的文件仍是 <清单>。
当前冻结快照：<全部文件SHA256>。下面是协调者已核实的发现：
<逐项证据、定位、期望行为、需要复验的范围；不要附未核实的猜测>

解冻后逐项修复，在TASK中同步实际范围和时序；不得删验收项、放宽阈值、
改随机范围规避失败，或借机改其他卡。需要改冻结规格时先报告给协调者。
修订后重跑正式机器门/可执行性检查，重新冻结并输出新SHA及逐项处理结果。
由原非作者审查者按新快照复审。文案修改同样使旧PASS失效。
基础设施失败独立记录，不当作脚本返工轮数；三轮仍不通过交协调者判断。
```

## 协调者最终检查

作者就绪、机器门通过、可执行性证据和独立审查是不同状态。正式纳入需确认所有门针对同一最终快照，并完成加载器/元数据兼容；原型不能因基础 harness 跑通就进入卡池。

专项目录与训练组必须显式接入，不能直接放进现有 `cards-synthetic/` 让读取整目录的旧配置静默扩大卡池。正式目录、采样份额、训练和评测配置另行确定。

派发工具/model/并发按本轮授权和实际资源选取；使用独立最小上下文，记录 model 与 reasoning_effort，不由作者更换原作转写后端或取消其抽检规则。本文不启动子代理。

## batch3 执行后补充（2026-10-01）

- 正式工具已就绪。作者 READY 前使用单卡 `specialist_validate` 自检，必须0errors，不凭harness退出0或印象填写段结束。禁止作者对批次父目录使用 `--all`。协调者才跑整批。
- 公共骨架：main立即spawn；boss内显式 `set_enemy_flag(ENEMY_NO_BODY,1)`、`set_invuln`、`phase_begin(0,pattern,1800,0)`；90帧开场等待在pattern。spawn参数是drop_table/score/sprite，不是flags。
- machine-spec每rank必须实质覆盖firstbirth、warn/active/fade、交接/中段、lastbirth、精确expiry零场和frame1800零场；先独立推导，再实际采样，工具动态coverage可能在静态缺项修好后才显现。
- 不能只堵四角：用完整参数域的几何上下界检查宽大永久安全带；有限点检查幸存不等于普遍漏洞，亦不应要求所有80个固定点试验全死。
- 通道净空应按自机中心计算：两条中心线距离−激光完整宽度−2×实际自机半径，当前压力检查保守半径4.5px；记录高速4.5/低速2.0和motor限制。
- 当前控制器失败只代表NOT_PROVEN；补充控制器或预测窗口必须保持同一真实物理条件，单独记录代码SHA/配置/轨迹，不能伪装成原18f结果，也不修改训练观测或reward。
