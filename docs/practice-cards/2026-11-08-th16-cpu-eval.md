## 模型与口径

- 权重：`runs/job-b3ef72c1ca44515d/20261006-151317-request-light-shift-k8/checkpoints/best.pt`，update 1000，262144000 env steps。
- 部署图：`dist/b-request-light-shift-k8-b2048-best.onnx`，graph7，2048 弹 / 256 敌 / 64 激光输入行，v8 特征、set_attn_v3、子弹 K64 / 激光 K8。
- 81 段正篇为 rank3（Lunatic），29 段 Extra 为 rank4。每段 10 个环境各记第一次结束的局；固定基础 seed12345，贪心 FP32，自由躲弹，保留训练运动层，每帧决策。不使用镜像或额外判定半径。
- 环境复用生产 `EnvWrapper`、特征化器和 native `stg_rl`，每段最大帧数为本卡 limit+300，避免旧 checkpoint 的 3600 帧上限截断长卡。
- 四项明确不做与三张曲线暂缓继续排除。这批仍是工作区转写稿；试测没有完成独立保真审核，也没有收卡、训练或修改部署包。

## CPU 性能

机器为 Intel Xeon Gold 6330 @ 2.00GHz，Linux，torch 2.14.0+cu130、ORT 1.30.0 CPU、stg_rl 0.4.7 / ENGINE_VER35。112 个逻辑 CPU 可用，本次核验的 cgroup CPU 配额不限额；主机有其他负载。

评测与渲染进程均结束后，使用单线程、顺序执行的 ORT CPU Session 串行计时。每段从 AI 尚存活时每 128 帧采样的场景中保留弹与激光总数最多的一帧；该帧不是全卡逐帧峰值。每段先预热 12 次，再测 100 次，共 11000 次。

| --- | ---: |
| 平均 | 1.099ms |
| P50 | 0.998ms |
| P95 | 1.615ms |
| P99 | 1.629ms |

调用包含图内特征提取、Top-K 和网络，输入 batch=1；不含游戏进程读内存、C 侧输入打包或其他游戏开销。本次采样的推理调用均低于 60fps 的 16.67ms 帧预算，但不能据此保证实际游戏整帧耗时，也不能直接换算为另一台 Windows 电脑的性能。

另记录了四进程评测期间的训练侧 CPU 时间：一次推进 10 个环境，按实际计时次数加权，特征提取平均 3.83ms、网络 4.73ms、Python 环境包装 3.08ms，其中 native engine 0.56ms。逐卡吞吐中位数约 874 环境帧/秒。包装层已包含 native 时间，不能相加；自动重开后的环境仍参与批量计算，不能把这些数字解释为单局延迟或只统计首次轨迹的吞吐。

## 静止 GIF 与耗时

直接复用 `stgtranscribe.preview.render_card` / `_job` / `write_index`，没有改渲染器。8 个进程，每卡内部 1 线程，seed1，自机固定 `(0,384)`。覆盖现有渲染器识别的活动弹幕窗口，每 3 个游戏帧取一帧，50ms/帧，按原速循环。每段另有 4 列、8 帧拼图；正篇 rank3，Extra rank4。

110 个 GIF、110 张 PNG 全部完成，错误 0；GIF 合计约 2.79GiB。4 路评测最慢分片耗时 756.9 秒（12分37秒），8 路渲染耗时 768.1 秒（12分48秒），二者有重叠；从评测启动到最终 ORT 完成约 20分42秒。
