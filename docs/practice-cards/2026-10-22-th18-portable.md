## r2：修正配置参数路径

同日用户实机反馈 `No run configuration .js file given`。启动器虽已生成 `thcrap/config/ai.js`，传入的参数却是 `config/ai.js`。官方 loader 的 `load_config_from_file` 对相对路径只检查反斜杠，因此它会额外添加 `config\`，得到错误的 `config\config/ai.js`。不需要修改全局 `config.js`。

独立核对官方 2026-09-04 loader（二进制 SHA256 `f2633fd08f791ab73f43b0cdff72076fb44b342a3ac7f2d796e227b5082713ab`）：VA `0x4027da` 检查相对路径、`0x4027eb` 搜索反斜杠，未找到则在 `0x402907` 添加 config 前缀；绝对路径分支 `0x4029c8` 直接复制参数，`0x402a00` 读取 JSON。

修正仅涉及启动命令构造：复用实际生成配置的绝对路径，并与 loader／游戏参数分别引用。新增短回归断言调用真实生产函数，验证含中文和空格的完整三参数命令，旧行为失败后修正通过。实际执行：

检查通过：严格 x86 编译、命令构造回归、PE 导入、固定输入／导入闭包、ZIP CRC／逐文件字节。没有重跑训练或修改第三方 loader、AI 适配器、权重和运行库。当前 Windows 启动结果仍待用户验证。
