首个字节码原型位于 [tools/th18-import-prototype](../../tools/th18-import-prototype/README.md)：独立 Python 前端直接构造现有字节码镜像，Rust runner 通过公开接口执行真实 stg-core。该阶段未改引擎；随后源码路径的进展见下节。

22 份本机 TH18 二进制解析成功，798 个真实 sub、22,721 条指令。之前 838 的统计多算了非 raw 解码中的 40 条前向声明。真实 `st04::GirlD01_at2` 实验模式四档轮数／弹数／间隔通过；Normal 重跑轨迹与 checksum 一致，但不是原作对拍。

长期约束与本次发现：

- goto 与栈运算分开处理；ZUN goto 还重设脚本时钟，wait 减时钟而不直接 yield。TH18 本机原生地址与检查结果见原型 README。
- 参数 `[-1]` 是 peek；统一收栈读指令头 `+0xc` 低字节，不是 `+0xb` 参数数。旧 renkolab 格式笔记相关表述不能照抄。
- f32 转定点会影响分支：0.999999f 原生转整是 0，Q16.16 量化可变成 1。严格原型拒绝源浮点；`--demo` 明示近似，不可笼统宣称控制语义完全一致。
- EX2 出生动画有真实位移／半速／碰撞门和变换计时后果，不可作为纯视觉忽略。当前 demo 省略它，另替换随机流、弹型半径和发射源，不能收为保真训练卡。
- 原作摘录、派生镜像、trace、构建产物只放已忽略的 `transcribe/work/th18-prototype/`。正式化和新增引擎机制仍须按架构约定确认。

## 用户确认源码路径与标签跳转

2026-10-23 用户要求产物便于人工校对，明确确认我方 ECL 加入标签／goto，但标为不推荐常规手写；简单分支和 for／while 应自动恢复。已在 stg-engine 编译前端实现 `label:`／`goto label;`：同 sub、顶层标签、局部初始化在前，不允许跳入嵌套作用域／与同 sub 的 mark 混用。没有新增运行时字段或指令，ENGINE_VER24，旧 golden 逐字节相同。
