# 下一步：先丰富训练数据

更新：2026-11-08。用户在本轮收尾时明确：已经发现高版本弹幕上的弱项，下一阶段优先增加训练数据与运动机制的丰富性；大注意力层、Perceiver 等架构方向延后。本文是当前研究顺序的统一入口，旧计划里的“下一步”按其记录日期理解。

## 已经发现的问题

部分持续转向弹幕是当前模型的明显弱项。把持续角速度置零后，四面御札非符 `s4_b3` 从2/30提高到29/30，Extra「弾幕の玉繭」`s7_b6` 从0/30提高到10/30。转向改变也使弹量减少约18–27%，因此尚不能把收益全部归因于编码器。

训练覆盖不足与运动表示不足都是候选解释。现有子弹 token 只有位置、速度、半径，缺少加速度、角速度和跨帧运动历史；但实际训练采样中的非线性运动覆盖尚未量化，也没有证明增加输入或扩大网络是必要解法。

春季终符 `s6_b11` 最初10局为5/10，扩到三批种子后为7/30，并非稳定的容易段。它在无DPS外壳中按时间换段，原作还可按血线提前换段，直接对照人类难度有边界。

追敌实射改善了部分道中：六段合计由无敌组16/180提高到可击杀组32/180；另有若干段落实际减压不足。击杀假设暂降优先级，尚未被全面证伪。用户已停止定时击杀代理实验，后续沿用真实目标点追敌的研究口径，不恢复该代理方案。完整证据见[难度假设实验](practice-cards/2026-11-08-th16-difficulty-hypotheses.md)。

## 当前优先工作

1. **把已有高版本转写稿整理为可靠的数据候选。** 从 TH16／TH18 已有产物继续机器验收、独立源语义审核及必要返修，按既有流程收卡。作者交付或一次 CPU 试测不等于已验收；沿用明确不做／暂缓清单。
2. **扩充真实运动机制与组合覆盖。** 优先考虑出生后持续转向、角速度变化、标量／向量加速、延迟变速、反向与再瞄准，以及这些行为与不同出生位置、速度、密度和其他弹型的组合。可使用其他已转写原作攻击及独立合成组合；具体数量与采样配比另定。
3. **按真实轨迹核对覆盖。** 区分发射器旋转与子弹出生后转向，关注进入近身区域时运动效果是否仍在生效。结合实际训练起点、采样记录与轨迹做必要盘点，标签数量不能直接当作训练可见帧占比。盘点服务于选数据，不再重复证明本轮已发现的弱项。
4. **用现有结构验证数据扩充效果。** 训练／留出按源攻击或运动家族区分，保留独立泛化测试，比较新运动家族表现、旧TH06能力和操作稳定性。优先保留本轮诊断卡作探针，避免只换随机种子就宣称泛化。训练父权重、划分、混合比例、预算及资源参数仍须在执行方案中确定。

本阶段沿用已经验证的模型／观测结构、PPO 与运动层，先把数据因素测清楚。本次整理没有生产新训练卡或启动新训练。
