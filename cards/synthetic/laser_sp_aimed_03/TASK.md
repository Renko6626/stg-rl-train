# 左右交替的冻结瞄准

## 设计与参数

本卡只有一只固定、无敌、非体碰 boss，激光是唯一威胁。phase 0 使用 `phase_begin(0, aimed_pattern, 1800, 0)`；boss 设 `ENEMY_NO_BODY`，保持存活直到 phase 结束。实测调度中 boss 在 frame 2 出现、任务在 frame 3 开始，phase 在 `PHASE_ENDED@1803` 结束。开场等待后从 frame 95 起发射，段结束前不截断最后一轮。

每组 3 条同帧出生的直线，从 `x=-176` 与 `x=176` 两个边缘原点交替发出，`y=64`。每条长度 `560px`、`start=0`，无速度、无旋转、无挂靠。每条都在出生同帧调用一次 `lz_aim`，之后方向和原点冻结：中线 `off=0deg`，两侧线 `off=-22deg/+14deg`。本批协调者批准的公共修正允许每组包含一条 `off=0deg` 直瞄线；其余偏角绝对值在 8..60deg 范围内。旧线不追踪自机，也不在预警、生效或收缩期间转向。

开场 `wait(90 + rand(2))`，离散均匀随机数是 `[0,2)`，即 `0..1` 帧。组间每次 `wait(base + rand(jitter+1))`，均匀整数范围分别是 `[99,106)`、`[90,99)`、`[82,89)`、`[72,77)`，即表中的闭区间。实际 seed 1/7 的首生帧均为 95；跨种子 / rank 实测的末生帧最大为 1428，末条回收帧最大为 1683。上表用随机上界计算，保守覆盖未采样随机序列。脚本没有整数转 fx/angle cast；坐标、长度、宽度用 fx 字面量，方向偏角用 `deg` 字面量，没有 `int as angle` 位穿透。

## 联合空间与避让窗口

训练自机 clamp 为 `x∈[-192,192]`、`y∈[0,448]`。原点到同侧最远边界点距离约 384.33px；到对侧最远角点距离 `sqrt(368²+384²)≈531.87px`。因此 560px 线段对全 clamp 矩形的最坏端点仍留约 28.13px 长度余量，直接瞄准射线不会因长度不足而越过对侧角落的目标。角度跨度、原点与长度联合覆盖范围按上述 clamp 推导；seed 1 的无输入 `--at` 采样中，左/右原点角度为 39.19..75.20deg / 96.81..132.81deg，角度范围来自实际目标位置而非写死输入。

每组直瞄中线在出生时穿过当前自机坐标，预警结束后仍是静止威胁；rank3 最短预警 45 帧，其他档更长。直瞄线要脱离碰撞带，中心位移必须超过 `width/2 + player_hit_radius + hit_extra`；rank3 的激光项是 6px，再加真实自机半径与环境 `hit_extra`。这是联合最不利几何条件；具体可达余量还取决于真实动作速度、斜向归一化、命中扩大量和边界动作，本作者没有运行真实玩家避让检查器，也不把 45 帧换算成未经验证的位移。偏角线在直瞄线两侧拓展压力，但不作为直瞄线可躲的证明。

组间最大间隔均小于本档 `warn+active`，所以从首组预警到末组自然回收没有无预警 / 无生效激光空档；最长内段空档推导为 0 帧。收缩态也计入总池占用。基于最短组间隔及 `warn+active+fade`，rank0/1 最多 3 组并发（9条），rank2/3 最多4组（12条）；预警+生效同样不超过12，含收缩也不超过12，分别满足16/20预算。最后回收后至1800最多71帧，仍小于90帧。
