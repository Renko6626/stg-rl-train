# 合成成品卡

本目录包含30张原作底子上的激光变体、20张从零制作的激光专项。20张专项中17张启用（12训练候选、5held-out），另3张 `enabled=false`：laser_sp_corridor_01、laser_sp_corridor_03、laser_sp_sweep_02。

暂停原因是既有控制器尚未找到完整避让轨迹，不是无解证明。已启用的卡也只代表当时有限样本证据，不宣称每档/每种子都已证明可躲或有训练收益；详见[第三批结果](../../docs/practice-cards/2026-10-01-batch3-results.md)。

题材、底子、生成方式、专项类别和留出标记保留在meta，不再按批次/激光/暂停状态建成品目录。新生成流程见[synthetic生产入口](../../transcribe/synthetic/README.md)，加载与筛选见[卡库总览](../README.md)。历史TASK与machine-spec留作材料，新流程不默认沿用逐文件hash和冻结门。
