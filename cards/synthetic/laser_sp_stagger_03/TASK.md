作者设计，contract v1。此文件与 `main.ecl` 一同绑定作者阶段快照；当前状态只表示基础 harness 自检完成，真实玩家避让与独立审查仍待协调者安排。

## 练习动作与布局

纯激光。方向按组交替：每组四条平行长线，下一组切换水平/垂直；不连续旋转、不移动已出生激光。每条线从预警出生位置即固定，因此当前预警给出完整方向和位置，生效期间几何不变。每组全部四条在同帧建立，线与线间保留通道；两个方向可在组间重叠，形成可读的交点和可等待旧线消退的窗口。

玩家边界按协调者给定的真实范围 `x∈[-192,192]、y∈[0,448]` 评估。水平线的原点为 `(-320,y)`、方向 `0°`、长度 `640`，因此横穿完整玩家宽度。垂直线原点为 `(x,-96)`、方向 `90°`、长度 `640`，覆盖完整玩家高度。水平位置族包含 y=0 与 y=448 的边界线；垂直位置族包含 x=−192 与 x=192 的边界线，避免设计上遗留固定边沿安全带。各向组内相邻线中心间距为 96 或 112 px；最窄通道中心宽度为 `96 − width`，逐档为 90/88/86/84 px（尚未扣除玩家判定半径和 `hit_extra`）。这些中心宽度只是几何描述，不证明有完整可达避让轨迹。

等待型决策来自旧方向仍生效时观察新方向预警：交接时横竖组会交叉，但四线组之间仍有多个开放矩形通道，旧组结束前允许沿当前开放区等待。离开已标记光束至相邻安全槽中心的保守直线位移按半个最窄中心间距、激光半宽和玩家半径相加：rank3 为 `48 + 6 + 2.5 + 4 = 60.5 px`（使用默认角色半径 2.5 px 和保守 `hit_extra=4 px`；配置默认 `hit_extra=[0,0]`）。余量估算采用项目角色表低速 `2.0 px/frame`、`frame_skip=1`，并按手部运动层最不利 `hold≤6` 与 `delay≤2` 预留 8 帧，最短 45 帧预警剩余 37 帧可移动约 74 px，算术余量约 13.5 px。若使用高速 `4.5 px/frame`，预算更宽；本卡不要求策略使用该档。该单线位移预算没有模拟旧激光造成的路径阻断、边界钳位和运动层隐藏状态下的真实路线，因此不能替代真实动作检查，也不构成全实例可解结论。

## 随机范围与联合约束

`relay_pattern` 在第一个组之前用共享模拟 RNG 抽初始轴相位 `rand(2)∈{0,1}`；后续每组严格交替，15 组覆盖两个方向。水平与垂直各抽一个初始等级相位 `rand(7)∈[0,6]`，半开 RNG 区间；之后该方向等级按模 7 轮转，7 或 8 次出现会遍历全部等级。等级 0/6 不加抖动以保证边界线落在玩家边界；等级 1..5 抽整数抖动 `rand(17)-8∈[-8,8]`，两端可达。

水平基准 `48 + level×40 + jitter` px；四条线位于基准的 `−160,−48,+48,+160` px。其随机联合结果保持各线间距 96/112 px，最小中心通道 96 px；不同 level 和抖动改变整组位置，不独立抽各线，避免平行线顺序反转或意外重叠。垂直基准 `−48 + level×16 + jitter` px；四线偏移同为 `−144,−48,+48,+144` px，最小中心通道 96 px，极端等级准确触达 x=±192。角度固定，不随机；位置等级、抖动和首轴相位是随机项。seed 1/7 的 `--at` 快照用于展示种子会改变几何；两种子不是完整随机域的证明。

## rank 与时序

rank 0/1/2/3 使用完整判定宽度 `6/8/10/12 px`、warn `90/75/60/45` 帧、active `150/170/190/210` 帧、fade `12` 帧。强度随 rank 提高时预警缩短、线宽增加、生效时间延长；线位置族、四条同组结构不变。

`boss_main` 固定生成于 `(0,64)`，sprite 参数为 `1`，hp=1000、drop=0、score=0；启动时置 `ENEMY_NO_BODY` 并设 65535 帧无敌。它以 `phase_begin(0, relay_pattern, 1800, 0)` 管理唯一 1800 帧非符段，`wait_spell` 后继续存活。无额外敌人、普通子弹、玩家碰撞标志或生效期瞬移；无敌时间长于本段，`hp_threshold=0` 不提前结束。

主时序经 harness 帧号核对：首组在 frame 94 出生（此前 frame 93 仍为 0 条），组间隔严格 98 帧，15 组帧号为 `94 + 98×n`（n=0..14），末组 frame 1466。逐档最后自然回收为 rank0/1/2/3 的 frame `1718/1723/1728/1733`，均早于 1750；段结束事件在 frame 1803，最后回收到段结束至少留 67 帧。warn+active 的最长单组寿命为 255 帧，小于三个组间隔 294 帧；含 fade 的最长寿命 267 帧，也小于 294 帧，故任意时刻最多三个组在池内，即 12 条；warn+active 内同样不超过 12 条，满足 16/20 预算。组预警开始间隔 98 帧，但前组持续生效超过该间隔，内段没有无预警/生效激光的空档；15 组之间位置/方向持续变化。最后一组之后的自然收尾空档按 rank 为 82/77/72/67 帧，低于 90。
