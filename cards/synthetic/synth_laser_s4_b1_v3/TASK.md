# synth_laser_s4_b1_v3

## 变异几何与时间

- 开场等待 120 帧；每轮创建 1 条颜色 15、长度 360px 的旋转线，原点从 `x∈[-80,80]`、`y∈[80,160]` 随 seed 采样。
- warn 60、active 90、fade 12；rank 0/1/2/3 的完整宽度分别为 6/8/10/12px；`lz_omega=96 BAM/frame`。
- 生效期间每 30 帧用 `lz_origin` 将原点依次平移到右、右下、下方，且 `lz_alive` 守护写口；seed 1/7 的起点和角度应有差异。
- 每 270 帧一轮，共 8 轮；首条出生 harness 帧 123，末条出生 1743，全部在 2400 帧内回收。
- 最后一条自然回收帧按 harness 帧序 `1743 + 60 + 90 + 12 = 1905` 计算，未超过时限。

## 关键帧预期

- 124：1 条 state 0，`start=0,end=360`，原点和宽度在声明范围。
- 154：1 条 state 0，原点为第一次平移后的 `(x+32,y)`。
- 184：1 条 state 1，原点为第二次平移后的 `(x+32,y+24)`，omega 为 96 BAM/frame。
- 214：1 条 state 1，原点为第三次平移后的 `(x,y+24)`；244：原点保持第三次平移位置。
- 274 及 284：0 条；394：第二条 state 0。
