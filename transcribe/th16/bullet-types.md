# TH16 弹型、颜色与基础半径

`etSprite(id,type,color)`与EX SETSPRITE使用原作type/color；源type不能直接当目标appearance。

2026-11-07用户明确允许TH16复用已核相同的TH18 type 0–43逻辑槽，卡元数据仍为`source="th16"`。使用本目录的[touhou-bullets.ecl](touhou-bullets.ecl)，复制整份或所需常量到单卡编译目录。无需修改引擎目录或升级wheel；当前ENGINE_VER35/wheel0.4.7已包含这些槽。

依据是已有[TH16/TH18逐型对照](../../docs/investigations/2026-11-05-th16-th18-bullet-types.json)：0–43的弹型记录前0x110字节相同（含基础半径与色配置）、所查ANM脚本相同、五张纹理RGBA一致。本次核对目标目录radius_raw与该记录一致，没有重新逆向。此结论不自动覆盖碰撞公式、出生时序、EX或未知扩展字段；这些依照对应专题及已批准取舍处理。未核TH17，本轮映射直接由TH16/TH18证据建立。
