## 一张卡怎么读

1. 从任务和原文确认入口、结束、难度、必要初始化及源帧／卡帧关系；准备者负责边界，作者不恢复整关。
2. 读反编译难度掩码、压栈及栈索引，再查[指令表](instructions.md)恢复调用参数。
3. 按本卡涉及的机制查专题，保留内部危险行为、随机取样点、共享状态和主要轨迹；直接使用[已批准取舍](transcription-policy.md)。
4. 目标语法以交付时引擎`docs/ecl-lang.md`为准。弹型用本作[touhou-bullets.ecl](touhou-bullets.ecl)，卡外壳与检查见[验收附录](validation.md)。

## 共通执行模型与本作差异

- 指令时间标签、`wait`、世界帧、敌存活时间与段计时器分开；同步调用与async共享敌级变量和发射器配置。
- 敌有ABS与REL位置层，最终位置合成；TH16坐标以画面上方中点为`(0,0)`，不套TH06的x减192。
- EX记录每弹**18条**，每条`0x2c`字节；TH18的24条容量不可照搬。ACCEL/VELTIME的高角分支只有TH16三段规则，详见[EX专题](ex-effects.md)。
- TH16专用变量`−9903 SUBSEASON`和1000/1001季节掉落指令见[基础语义](mapping.md#35-游戏内变量与随机伪变量)及[指令表](instructions.md#调试与作品专用入口)。TH18的HYPER变量与1002–1020不归TH16。
- 本轮提供已核同值的0–43弹型别名，经用户明确许可复用现有TH18槽；[弹型专题](bullet-types.md)列半径、有效色号与证据。社区50型名单不当作本作库存。
- 训练采用无敌独立躲弹外壳。普通掉落、纯表现、出生动画及波次交接按[转写口径](transcription-policy.md)省略；本攻击内部的发弹、运动和危险区照常保留。
