# TH18 单攻击转写的统一口径

2026-11-05。本文将已确定写法、任务单须明确的差异和暂缓范围集中起来。用于主会话准备、作者与审核者共用；不增加新的引擎机制、批量命令或验收状态。先读[主线教材](mapping.md)，普通opcode按[指令索引](instructions.md)定位。

## 当前范围与处理方式

| 类别 | 统一做法 | 报告要求 |
|---|---|---|
| 已核且可等价表达 | 按本作语义重组目标程序，保留时点、共享范围和顺序 | 给源位置→目标位置、独立期望和实际检查 |
| 训练外壳 | 按任务单使用无敌、开场缓冲、单段结束事件 | 分开记录源攻击时轴和目标全局帧，不改原攻击内部周期 |
| 已知目标差异 | 使用已核单位/数值实现；影响另行说明 | 记录Q16.16/BAM取整、原作浮点、RNG等实际边界 |
| 物理或机制近似 | 仅采用任务单中明确接受的方案 | 列原行为、目标行为、改变的几何/时序/分布及依据 |
| 实际命中未解机制 | 保留原值和依赖，写 `status: blocked` | 指出最小缺口和受影响攻击；不把整关自动停掉 |
| 实际使用曲线激光 | **暂时不转写该攻击** | `status: blocked`，原因注明“曲线激光暂不做”及源位置 |

`blocked` 沿用现有单攻击report字段，不是在旧TH06流水线里新增TH18状态。主会话可把该攻击登记为暂缓；独立、无需该机制的其他攻击继续。某个rank/分支是否实际使用，按任务范围与可验证控制流判断，不能仅在文件中搜到一个opcode就跳过整份ECL。

## 曲线激光的明确边界

用户本轮明确要求曲线激光暂时不做。以下规则同时适用于作者、审核者与主会话：

- 所选攻击实际执行 `711 laserCuOn`、依赖曲线的历史节点/局部切线，或依赖仍存活曲线产生的危险区，就暂缓该攻击。
- 不删除曲线后提交一个缺少危险区的版本；不默认换成直线、多个短直段或普通弹。
- 不为这项任务扩展引擎曲线实体，也不为绕过限制另建近似机制。
- Line与Infinite直线仍按[激光表](lasers.md)及[换算案例](conversion-examples.md)处理。未知713不是已经支持的直线替代品。
- 若曲线只在未选rank或确实不可达分支出现，可以给出控制流依据后继续当前范围；不能靠删掉分支制造“不可达”。

这里暂缓的是曲线激光。普通子弹的曲线运动、贝塞尔/Hermite敌移动、持续转向的直线激光分别查对应机制，不因名称含“曲线”就一并停掉。

## 已确定的转换规则

1. **两套语法分开。** 原作侧使用指定thecl18和eclmap，301名为 `enmCreateA`。目标使用int/fx/angle；一圈可写 `360deg` 或 `65536 as angle`，不能写非法的 `65536bam`。
2. **时间按实际执行推导。** 原作跳转可重设脚本时钟，wait也改时钟；目标wait是任务让出。循环退出后的等待、async下一帧首跑及源/卡帧平移分别核。完整配方见[转换案例](conversion-examples.md)。
3. **发射器按读取者归属重组。** 原作同敌跨async共享，目标每任务私有。主任务改配置时，发弹任务必须在对应帧读到正确值；只传一次快照不能复现后续共享改写。
4. **动态值直接表达。** 按值xform保存配置值，出生值用at_spawn，效果进入值用at_effect；rand沿原取样阶段和共享范围。不能因为参数动态就量化、取中值或一批共用逐弹随机。
5. **编号按语义映射。** 弹型/颜色查本作表；普通层速端点换步长用M−1，M=1单独处理；插值用EASE名称，7/8/17用状态槽；方向哨兵先解码再转BAM。
6. **保留实际状态影响。** 换图不等于换半径，DELAY不等于停速，VELTIME不等于持续追踪。并行EX按原作更新顺序分析，不能把所有持续效果都串成wait。

这些是实现方法，不是新增的物理近似授权。

## 弹型与半径的一致性要求

2026-11-05初查旧12形映射存在半径和缺型差异，见[半径对齐报告](../../docs/investigations/2026-11-05-th18-radius-alignment.md)。随后引擎ENGINE_VER31追加按作品区分的TH06十型和TH18四十八型，新转写使用生成词表中的本作弹型和原作色号，基础半径按原生值转Q16.16。旧192项保持，不能继续把旧候选的半径偏差当作新卡默认取舍。

分别核源type→目标形/色/基础半径、出生及EX中的半径/缩放/换型变化、玩家判定参数与碰撞公式；出生动画附带的减速和无判定窗口按已批准的例外处理。Q16.16正常量化允许在原数值最近可表示值层面比较；它与2.4被改成2或2.8被改成5的差异不同。新表解决出生基础尺寸；通用动态半径/缩放写口仍未增加，现有换图操作仍保留出生半径。

## 已批准：按作品区分弹型，碰撞算法选择后置

2026-11-05用户确认，同一种外观可共用贴图，弹型身份与物理半径按来源作品区分，例如TH06米弹与TH18米弹分别记录，不能因都叫RICE就强制合并。任务资料使用“作品/版本＋原type＋color”标识，分别列目标外观、原作半径和当前目标实际半径。随后已授权并接入生成的 `TH06_*` / `TH18_*` 词表；它们是普通内容常量，须加入卡片编译目录，不是新的全局关键字。

当前转写继续使用引擎现有 `距离² <= (弹半径+玩家半径)²`，如实记录与原作的公式差异。以后是否提供碰撞算法选择，留到后续引擎修改；**不作为切分、转写或审核的前置条件**，不因这项已接受的差异单独判blocked，也不通过修改弹半径来补偿公式。

转写继续恢复控制流、移动、发射和EX。新表在出生时直接设置物理半径，普通弹不为静态半径挂xform；引擎和训练wheel须使用同批新表。既有卡不自动迁移。完整目录、生成入口和接入证据见[本轮记录](../../docs/investigations/2026-11-05-touhou-bullet-catalog.md)。

## 已批准：省略出生减速和无判定窗口

2026-11-05用户明确同意，为性能省略普通弹出生动画附带的短暂减速与无判定窗口，避免仅为出生阶段让所有普通弹挂上变换链。普通弹直接使用配置初速并参与判定；确有后续攻击变换的弹仍保留所需程序。报告可统一引用本节，不必逐卡重新请求；写明早期轨迹与首次可致死时点发生了变化。

此项许可只覆盖出生减速和出生无判定窗口，不包含基础半径近似、出生退位移、后续刻意设计的变速/冻结、DELAY、激光预警或其他碰撞门。其他EX的取样及执行时点仍按源逻辑推导，不能因为删去出生效果而随意提前。TH18生成态受计时与ANM转态共同影响，不能将整个state2一概解释为无判定；源事实仍保留在原生报告中。

## 系统性省略与外壳接管

现有躲弹转写省略不参与攻击行为的普通道具掉落、掉落奖励配置、计分/章节统计、纯音效、装饰粒子/动画、立绘、背景演出和UI；对话/调试/练习入口不作为实战攻击内容。TH06已在其mapping §8/9/11明确采用这类口径；TH18按本节区分纯表现与攻击副作用，并非存在一个自动删除所有同名opcode的预处理器。

| 内容 | 当前做法 | 保留的边界 |
|---|---|---|
| 普通掉落与奖励 | 不重现P、钱/点、命/炸弹资源、主/额外掉落和限时奖励；敌掉落表/分数置为无奖励配置 | 若某个“掉落”入口还会发弹、清弹、换状态，只省奖励部分 |
| 纯表现 | 省音效、震屏、装饰ANM/粒子、立绘、背景与显示信息 | 弹型/颜色映射仍保留；名称含ANM或特效不自动证明无物理作用 |
| 计分/章节统计 | 训练卡不模拟原作评分和章节奖励累计 | 攻击实际读取的难度/变量不能顺手删掉 |
| 原作击破与段落推进 | 无敌躲弹外壳，不依赖玩家DPS/掉落；单段开始/结束由训练外壳组织 | 本段内的移动、发射、变换、必要任务切换仍保留 |
| 波次/阶段交接 | 用户已接受独立训练时不复现上一段完整位置/尾弹/清场回调和逐帧交接 | 当前攻击自己的开场移动、首发等待和内部危险行为不能作为“交接”删除 |

原作出生特效可能伴随半速、位移或无碰撞窗，SIZE/HITBOX也会改几何；这些有物理影响。出生减速和出生无判定按上述明确许可省略，其余副作用不能归入“纯表现”删除。TH06的其他历史近似不自动成为TH18通用许可。曲线激光仍是暂缓整个实际依赖攻击，不是只删掉曲线。

Stage01这次所列573/574已核为限时奖励掉落配置，可归普通掉落省略；569/570已核到章节计数权重的登记/结算，不写本调用点的运动/发射状态，不再因助记名unknown就阻塞切分。具体静态证据见[状态表补充](enemy-state.md#6-stage01试切后补核的非阻塞项)。更上层统计用途未完整追踪，不据此给其他作品或实际读取统计值的特殊攻击作普遍删指令承诺。

## 已批准：道中波次暂按独立场景训练

2026-11-05用户确认，波次尾部重叠问题暂不阻碍分开训练。按已划定的编队单独制卡，不必复制上一波残留敌/弹，不强制合并相邻波次；记录原作重叠与训练隔离的差异。仍保留本波自己的完整攻击过程和共享状态；波内主动发弹/内部回调保留，纯服务于跨波交接的残留和收尾不追逐帧复现，尾部/时限在转写时安排。

切分缺口与转写缺口分开：阶段/波次边界、源位置和依赖已明确时，不因还没完成目标实现、逐帧对拍或每个计分/掉落说明而把整关切分判失败。实际会改变本攻击危险区、又没有已核做法或已接受方案的内容，才作为对应单元的具体待补。

## 已批准：击破速度奖励波单独训练

2026-11-05用户确认，已识别的道中Boss击破速度奖励编队可以切成Boss后的独立一波。Stage01 MainSub05/W05按Boss已结束、完整奖励编队处理，不继续用原作击破时刻或F门导致的部分出生作为切分阻塞；保留编队内部排程、参数与敌人行为。具体入口和40个计划创建实例见[切分指南](splitting.md#已批准击破速度奖励编队独立成波)。

报告分别写原作条件与训练固定场景，不把此规则外推到任意条件创建、未知指令、普通波次重叠或其他物理近似。规则已经由用户确认，后续worker可直接引用，不必逐卡重复请求。

## 需要集中写进任务单的取舍

同一组攻击可以引用一份共用brief附件，列出实际使用的方案和适用范围；worker不必每次重新发明。以下表给出待填写的决策点，不替用户批准新的近似。

| 问题 | 当前统一要求 | 不能自动沿用的做法 |
|---|---|---|
| 弹型/颜色 | 使用[弹型表](bullet-types.md)固定候选与色号；按实际type列决定 | 所有弹都换appearance0；按外观忽略半径差 |
| 碰撞公式 | 当前沿用目标半径相加公式，记录源公式差异；算法选择后置，不阻塞转写/审核 | 为补偿公式擅改弹半径；等待未来算法选择才开始转写 |
| 动态几何 | 按作品保留SIZE/HITBOX及换型半径的语义和实际支持情况 | 将公式差异的许可扩展为删除动态几何 |
| 出生减速/无判定窗口 | 按本页已批准规则省略，记录早期轨迹与致死时点差异 | 把此项许可扩展到出生退位移或后续攻击变换 |
| 冻结/其他无碰撞窗口 | 保留原有门或写清缺失门的后果，未接受就blocked | 借出生近似删除DELAY、激光预警等其他判定门 |
| 激光长度/宽度/扩张 | 先推导碰撞段和每阶段宽度；按本作分段公式 | 所有width统一除二；expand全部当无判定warn |
| 敌人体碰/受击/镜像/限位 | 沿上游恢复具体状态，见[敌人状态](enemy-state.md) | 敌永远无敌，所以所有敌判定和flags都可删 |
| 血量或动态rank驱动弹幕 | 保留攻击实际读取的驱动值/过程，或明确任务单指定方案 | 把LIFE一律替换满血，把原作动态RANK当难度DIFF |
| 实体池/预算/回收 | 区分原作实际截断、目标预算和池耗尽；记录证据 | 套TH06的640池/1024阈值后减路数，或加wait拆同帧弹阵 |
| 开场缓冲与单段时限 | 明确120帧外壳放在哪里，源起点、首发、段终点怎样对应 | 每个helper再加缓冲，或把攻击内部所有等待整体放大 |

纯声音、UI、计分/道具和装饰可按躲弹任务范围省略，但先确认它们不参与后续控制流、碰撞门或弹幕状态。ANM名字不能单独证明无物理影响；段回调/中断若会清场、终止任务或换状态，就要在单段外壳中保留所需后果。

原作浮点与目标定点、不同RNG算法会影响精确序列；这不自动把任何转写降级为近似，也不使主动改分布、时点、碰撞或轮数成为默认许可。报告描述具体影响，避免只写“引擎不同”。

## 段入口和交付的固定顺序

先定义攻击入口/rank/时间窗，沿同敌上游链恢复必需状态，再准备目标外壳。保留“状态从哪里来、在哪一帧读取、已接受哪些差异”的记录；不能用目标输出倒推原作初值。具体字段和步骤见[段入口重建](enemy-state.md)。

交付沿用 `out/main.ecl`、`meta.toml`、`report.md`，如实写source=th18。作者按[单元编号与验收](validation.md)同步 `card/<unit_id>/` 并运行共用 `stgtranscribe.validate`；TH18 不套旧时限/弹数预算。审核者从源独立推导至少3条数值锚点，未实际运行不称审核完成。自动通过不代表源语义正确或已完成原作对拍；批量切分、训练和自动收卡另行推进。

编译与检查命令见[教材第1章](mapping.md#1-先分清两个语言三种文件)，本轮补充例子的实际结果记在[验证记录](../../docs/investigations/2026-11-05-th18-textbook-verification.md)。
